# Pharmacy Database

A simple Pharmacy Database Management System built using SQL and MySQL.

## Project Overview

This project is designed to manage basic pharmacy operations, including medicines, pharmacists, customers, and sales.

## Database Tables

The database contains four main tables:

* **Medicines** – Stores medicine information such as name, price, and quantity.
* **Pharmacists** – Stores pharmacists' names and phone numbers.
* **Customers** – Stores customer information.
* **Sales** – Records sales and connects medicines with customers using foreign keys.
